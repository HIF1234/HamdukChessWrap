# Bundled engine: Stockfish.js 19 (lite, single-threaded)

`stockfish.js` and `stockfish.wasm` in this directory are the "lite single-threaded"
WASM build from https://github.com/nmrugg/stockfish.js (release v19.0.0), used
here to run real, in-browser chess engine analysis for the "Game Quality" wrap
slide (see `lib/engine-analysis.ts`).

- Upstream: https://github.com/nmrugg/stockfish.js
- Engine: https://github.com/official-stockfish/Stockfish
- License: GPLv3 (see https://raw.githubusercontent.com/nmrugg/stockfish.js/master/Copying.txt)

These files are served as-is and are not modified.
